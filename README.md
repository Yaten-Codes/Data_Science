
# 📘 Data Science & Visualization Notebooks Collection

This repository contains a series of Jupyter notebooks covering essential topics in data analysis, visualization, and statistical modeling. The work spans practical applications using real-world datasets including satellite imagery, astronomy FITS files, economic indicators, sports analytics, and movie databases.

---

## 📚 Table of Contents

### 🔢 Data Processing & Analysis
- **Notebook06**: *Intro to Pandas* — Learn the fundamentals of data manipulation with Series and DataFrames.
- **Notebook09**: *Pivot Tables in Pandas* — Use pivot tables to group and summarize automobile data.
- **Notebook07** & **Notebook08**: *MovieLens Case Study* — Explore and analyze movie ratings, tags, and metadata using pandas.

### 📊 Data Visualization
- **Notebook10**: *Data Visualization with Matplotlib* — Plot economic development indicators from World Bank data.
- **Notebook11**: *Advanced Plotting with Folium* — Create geographic overlays of CO₂ emissions by country.
- **Notebook13**: *Smoothing Time Series* — Use moving averages to smooth historical temperature data from Barcelona.

### 🛰️ Scientific & Technical Data
- **Notebook04**: *Satellite Image Analysis* — Visualize and analyze satellite images using NumPy.
- **Notebook05**: *Quasar Image Notebook* — Display and interpret FITS format astronomy images of quasars using `astropy`.

### 📈 Statistical Modeling
- **Notebook14**: *Linear Regression with scikit-learn* — Apply regression to soccer player performance metrics using SQLite data.
- **Notebook15**: *Curve Fitting and Chi-Squared Tests* — Generate synthetic weight-loss data and fit models using SciPy.
- **Notebook16**: *Correlation & Probability Matrices* — Visualize inter-variable relationships in player data with heatmaps.

### 🧠 Machine Learning & Pattern Discovery
- **Notebook17**: *Mystery Dataset Investigation* — Identify which features influence the target variable in a dataset using correlation and regression techniques.

---

## 📦 How to Use

1. Clone the repo or upload the notebooks to Google Colab.
2. For notebooks that require files (e.g., `movies.csv`, `database.sqlite`), ensure they are in the correct Google Drive directory path specified in the code.
3. Run each cell sequentially and modify parameters as needed to explore further.
